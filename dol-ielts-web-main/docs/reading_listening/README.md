# Hướng dẫn cho Google Antigravity

1. Đặt toàn bộ thư mục `docs/reading_listening/` vào thư mục Django Project **có file `manage.py`**. Không chỉ tải mỗi Markdown nếu bạn cần xem các hình minh họa.
2. Trong Antigravity, yêu cầu: **“Hãy đọc `docs/reading_listening/READING_LISTENING_SPEC.md` và các hình trong `docs/reading_listening/assets/`, đối chiếu code trong `receptive/`, `reading/`, `listening/` cùng `config/`, chỉ phân tích và lập kế hoạch, chưa sửa code.”**
3. Sau khi Agent phân tích xong, mới yêu cầu triển khai từng Use Case, ưu tiên kiểm tra model và migrations đã có, sau đó UC-REA-01, và tiếp tục lần lượt.
4. Nếu AI Agent không mở được hình minh họa từ Markdown, hãy chỉ trực tiếp đường dẫn tương ứng trong thư mục `assets/`, hoặc cung cấp file Word gốc cho Agent nếu trình đọc hỗ trợ.

Bản trích xuất bám sát báo cáo tiến độ 2 và không thay thế bản Word gốc khi đối chiếu trình bày.
